# 分组模型表现监控

## 范围

以固定提示词定时生成 HTML，供用户比较各分组模型的实际输出；不生成自动分数，也不改变既有渠道探活、网关、计费或用户视觉模式。

固定提示词：`生成html，内容是svg绘制鹈鹕骑自行车2D动画，不用进行测试。`

每条任务包括名称、现有分组、完整 HTTPS 请求 URL、API Key、请求模型、API 格式、间隔秒数、启停、保留天数及最多记录数。支持 Chat Completions、Responses 和 Anthropic Messages；模型名按配置发送。Key 对应的实际分组由目标 API 的鉴权决定，管理员须使用该分组对应的 Key。

全局开关 `subnexus_model_evaluation_enabled` 默认关闭，与现有渠道监控模式独立。用户已明确选择按现有分组权限展示；列表和 HTML 详情均在服务端校验，不将 Key、请求地址或具体失败原因返回用户。管理员可在关闭全局开关和任务开关时主动进行一次私下测试；只有当前配置测试通过且管理员手动发布，任务才可以定时执行并向有权限的用户展示。

## 实现分工与边界

1. 独立追加数据库迁移，保存任务、加密凭据、调度租约和历史 HTML。历史迁移不变，旧版本可以忽略新表。
2. 后端后台循环按间隔领取任务，数据库租约避免多进程重复执行；限制并发、单次超时、响应大小与结果数量。关闭、编辑、删除和清理过程中不能让过期执行重新写回已失效结果。
3. 后台配置、任务管理和清理独立页面；用户监控入口提供分组下拉与历史分页。
4. HTML 以文本存储并通过已鉴权 JSON 详情返回，在无同源权限的 sandbox iframe 内展示。CSP 阻断外部子资源、fetch/XHR 和嵌套框架，sandbox 禁止弹窗和顶层跳转；卡片仅按需加载，隐藏页面卸载预览，最多同时播放 2 个动画，放大时仅保留 1 个。
5. 手动按任务或全部清理；自动保留策略在写入后及维护时执行。单条 HTML 上限 512 KiB、单次模型响应上限 2 MiB、任务上限 100、每任务最多 200 条，默认 50 条。

## API 合同

全部使用既有 `/api/v1` 响应封装及 JWT/管理员中间件。

- 管理：`/admin/model-evaluations/config` GET/PUT；`/tasks` GET/POST；`/tasks/:id` PUT/DELETE；`/tasks/:id/run` POST。
- 私下测试：`/admin/model-evaluations/tasks/:id/test` POST，异步返回 202；通过任务列表中的 `test_status`、`last_tested_at`、`test_error` 查看结果。状态为 `untested/running/passed/failed`。
- 发布：`/admin/model-evaluations/tasks/:id/publication` PUT，参数 `{published: true/false}`。服务端拒绝发布没有通过测试的配置，取消发布立即停止用户可见性及定时请求。
- 管理历史：`/admin/model-evaluations/results` GET；`/results/:id` GET/DELETE；`/cleanup` POST，参数 `task_id`（0 表示所有任务）、`all`（false 应用保留策略，true 清空所选范围）。
- 用户：`/model-evaluations/groups` GET；`/results` GET；`/results/:id` GET。
- 列表仅返回元数据，详情才带 HTML。历史列表支持 `group_id`、`task_id`、`page`、`page_size`；用户参数不能扩大权限。

## 验收

- 配置和模型透传、三种请求/响应协议、完整 HTML 提取、截断与无 HTML 响应处理。
- 关闭态不自动出网，只有管理员主动点击私下测试才生成请求；调度不重叠、超时释放、编辑/清理竞态、容量上限、保留和删除。
- 权限变化与越权详情返回、Key 加密和响应脱敏、URL 校验及重定向禁止。
- 分组切换、历史分页、悬停/键盘/触屏放大、预览沙箱、页面隐藏和销毁释放。
- 前端测试、类型/格式/构建，后端相关测试和构建，Wire 生成、数据库迁移隔离验证。

本轮是本地功能开发，不表示已部署。后续发布必须重新构建并完成发布门禁，最终生产切换仍由维护者手动执行。

## 预览运行边界

原始 HTML 在数据库中保留；浏览器展示副本移除外部资源引用、静态跳转和嵌套网页，保留内联 SVG/CSS/JS 动画。依赖外部库或图片的输出可能显示不完整，不会自动改写模型绘图。

保留任意内联 JS 时，浏览器 sandbox 不能彻底禁止子框架自身导航；CSP 资源策略不覆盖该行为。预览无主站同源权限，不能读取父页面 DOM/localStorage 或跳转顶层；支持 `credentialless` 的浏览器还会隔离网络凭证。不能把这些措施表述为任意 HTML 的绝对网络隔离。实际 Chromium 中已验证原始 SVG/CSS/JS 运行、父页面及存储隔离、外部请求及顶层跳转受阻；尚未验证 Firefox/Safari。

## 配置与访问

- 后台入口：`/admin/model-evaluations`，侧栏“模型表现监控”。先保存配置，点击“私下测试”，成功后检查生成预览，再点击“发布给用户”。定时执行和“立即检测”需要任务已发布且总开关、任务开关均开启。私下测试不受这两个开关影响，但同样受两个并发名额及 180 秒超时限制。
- 用户入口：`/model-evaluations`，位于渠道状态旁，仅在总开关开启后显示。分组采用 API Key 页面同一套可绑定权限（包含有效订阅），每次列表/详情都重新校验。
- 用户默认选择“全部分组”，将所有可访问、已发布分组的记录按生成时间从新到旧统一排列后分页。选择具体分组后只查询该分组；切换分组或切回全部均回到第一页。每张用户卡片在预览上方显示分组、生成时间、模型、任务名称、状态与耗时。
- URL 必须填写完整 HTTPS 请求地址，例如 `https://你的域名/v1/chat/completions`、`https://你的域名/v1/responses` 或 `https://你的域名/v1/messages`，并选择对应协议。编辑时 Key 留空表示保留现有值；若分组、地址或协议改变，必须重填对应 Key，避免将原凭据发送到新地址。请求模型填目标接口真实支持的模型 ID，仅改变模型可保留原 Key。
- 默认间隔 3600 秒、保留 7 天、最多 50 条；允许间隔 60–604800 秒、保留 1–90 天、每任务 1–200 条，最多 100 项任务。单次请求最多 180 秒，全局最多 2 个在途请求。
- 手动清理可选择所有任务或单项任务，按保留规则清理或清空该范围；任务删除会级联删除所属历史。失败结果同样计入上限。

## 2026-09-11 测试、发布与超时修复

- 截图中约 125 秒后收到 HTTP 524，表示上游代理等待响应超时，不能将其直接归因于 Key 或额度。原请求使用 `stream=false`；现在三种协议均请求流式响应，处理 SSE 文本及完整结束事件，也兼容供应商返回的完整 JSON。流式传输可减少等待整份 HTML 时的代理空闲超时；如果上游首个响应过慢、不刷新流或模型超过 180 秒，仍可能失败，不会自动重试产生额外请求。
- HTTP 524/504/408、鉴权、限流等使用不同的固定后台诊断；不保存供应商任意错误正文，避免反射凭据。用户列表与详情在服务及 handler 层清除具体诊断，失败只返回“生成失败”，同时清除失败 HTML；前端用户卡片也固定使用通用文字。管理员保留原因和耗时。
- 新任务默认未发布。已有任务通过追加迁移 `9015_subnexus_model_evaluation_publication.sql` 转为未测试、未发布，配置、加密 Key 和历史原样保留；升级后需要逐项测试并发布。原 `9014` 不修改。
- 修改分组、URL、协议、Key 或模型会撤销发布和测试通过状态，并隔离旧配置的历史。只修改名称、间隔和保留规则无需重测。再次私下测试会暂时取消发布，成功后仍由管理员手动发布。
- 未发布时所有结果仅后台可见；发布后用户可以查看当前配置的成功测试样本和后续定时结果，测试失败记录始终仅后台可见，后续定时失败对用户仅显示“生成失败”。仍执行原有分组权限和保留规则。
- 测试状态轮询每 2 秒一次、最多 120 次，完成/隐藏/离开页面停止；刷新可重新查询。过期或被中断的测试会显示失败，可手动重试，不会一直“测试中”。
